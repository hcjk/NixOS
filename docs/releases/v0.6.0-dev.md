# NexOS v0.6.0-dev — Milestone 6 NexFS

This development release completes the first writable NexFS v1 inode and
directory layer. NexFS remains an original NexOS filesystem and is not derived
from a Linux or Unix filesystem implementation.

## Highlights

- Fixed 256-byte, checksummed inodes for regular files and directories.
- Checksummed 256-byte UTF-8 directory entries with 240-byte names.
- Nested directories and persistent create, list, read, random write, rename,
  truncate, and remove operations.
- Twelve direct blocks plus one 512-entry indirect block, supporting files up
  to 2,146,304 bytes.
- Zero-filled file gaps and safe partial-block truncation.
- Inode and block allocation bitmaps with metadata and bounds validation.
- Dirty-before-write mount protocol and explicitly flushed clean unmount.
- Offline consistency checking for checksum errors, duplicate or leaked
  blocks, invalid directory targets, duplicate names, unreachable inodes, and
  dirty volumes.
- `nexosctl` commands for NexFS image listing, file import/output, directory
  creation, rename, truncate, removal, information, and consistency checking.
- A documented, versioned v1 layout and metadata update order.

## Verification

- All 23 host unit tests and all documentation tests pass.
- Strict Clippy checks pass with warnings denied.
- A real 16 MiB NexFS image passes create, directory, file import, list,
  rename, truncate, information, and offline-check operations.
- The freestanding x86-64 kernel builds successfully.
- QEMU BIOS and UEFI boot tests reach the NexOS 0.6.0-dev kernel monitor.

## Current limits

NexFS v1 has no journal, hard links, symbolic links, enforced access control,
or online crash recovery. Files use a single-indirect layout and are limited to
2,146,304 bytes. The kernel still exposes a monitor rather than a VFS-backed
userspace shell; processes, syscalls, VFS mounts, USB, and installation remain
later milestones.

## Release images

The release provides:

- `NexOS-v0.6.0-dev-x86_64.zip`, containing the 128 MiB BIOS/UEFI raw disk
  image for QEMU and VMware virtual hard disks.
- `NexOS-v0.6.0-dev-x86_64.iso`, a hybrid BIOS/UEFI CD image for VMware and
  compatible x86-64 machines with Secure Boot disabled.

The attached `NexOS-v0.6.0-dev-SHA256SUMS.txt` file contains the exact
SHA-256 checksums for artifacts produced by the release build.
