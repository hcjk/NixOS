# NexOS v0.10.0-dev — Milestone 10 safe installer

This prerelease turns the existing storage and filesystem foundations into a
guarded disk-image utility and an end-to-end NexOS installer.

## Highlights

- Adds standalone `diskutil` and `nex-install` Rust executables with
  interactive and explicit command-line workflows.
- Creates and validates GPT or MBR layouts, including combined BIOS/UEFI,
  UEFI-only, and BIOS-only guided layouts.
- Inspects partitions and detected filesystems, creates or deletes partitions,
  formats FAT32 or NexFS, and runs supported filesystem checks.
- Supports guided whole-image installation and manual ESP/root selection
  while preserving unrelated partitions.
- Installs Limine BIOS and UEFI boot files, the NexOS kernel, a NexFS root,
  release metadata, fstab, filesystem UUID, and a checksummed install manifest.
- Requires `--yes` plus an exact typed target for destructive commands and
  deliberately rejects physical raw-device paths.
- Prepares and verifies changes in a sibling image, uses backup/restore commit
  behavior for existing images, and performs post-commit verification.
- Updates release raw images to use the real combined GPT/NexFS installer
  layout.

## Verification

- Seven installer-specific tests cover raw-device refusal, confirmations,
  combined GPT and BIOS MBR layouts, NexFS formatting/checking, full guided
  installation, manual preservation, and refusal before target creation.
- The full host workspace test suite and strict Clippy checks pass.
- The freestanding x86-64 kernel links successfully as v0.10.0-dev.
- A 128 MiB image installed with the actual kernel and Limine passes eight
  installed-file checks and NexFS consistency/UUID verification.
- The installed image reaches the kernel monitor under QEMU Q35 through both
  legacy BIOS and UEFI.
- The release raw disk image and hybrid ISO are smoke-tested through BIOS and
  UEFI before publication.

## Known limitations

`diskutil` and `nex-install` are host-side image tools in this release because
the default NexOS prompt is still the kernel monitor. Raw physical disks are
refused. The installer does not resize partitions, detect mounted host image
volumes, or provide rollback inside a newly created image beyond its
transactional pre-commit checks.

Live USB HID/mass-storage transfers, downstream hubs, filesystem-backed ring-3
commands, SMP, NVMe, and real-hardware physical-disk installation remain future
milestones. Secure Boot is not supported.
