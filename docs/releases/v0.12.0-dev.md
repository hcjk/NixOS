# NexOS v0.12.0-dev — live USB class I/O

Milestone 12 turns the existing xHCI enumeration foundation into usable input
and storage drivers.

## Highlights

- Configures xHCI endpoint contexts and dedicated DMA transfer rings for
  interrupt and bulk endpoints.
- Accepts monitor input from USB boot-protocol keyboards without relying on
  the i8042 controller.
- Decodes USB mouse movement, wheel, and button events.
- Powers, resets, and enumerates one downstream hub level using xHCI route and
  transaction-translator context fields.
- Implements live USB Mass Storage Bulk-Only Transport with SCSI INQUIRY,
  READ CAPACITY(10), READ(10), WRITE(10), and SYNCHRONIZE CACHE(10).
- Registers USB media with the common block layer as `/dev/usbN`; `lsblk`,
  partition inspection, `diskutil`, and `nex-install` can use it.
- Retires disconnected root or downstream devices and reports disconnect
  counters.
- Moves per-controller runtime tables onto the kernel heap to keep nested hub
  enumeration within the boot stack.

## Release gates

- Host unit tests and strict Clippy checks.
- Freestanding x86-64 kernel and hybrid BIOS/UEFI ISO builds.
- Existing guided AHCI install followed by no-ISO SeaBIOS and UEFI boots.
- QEMU xHCI test with i8042 disabled, a keyboard, mouse, eight-port hub, and
  256 MiB USB disk.
- USB-only `uname` entry, injected mouse movement, read test, full
  `nex-install` onto the USB disk, cache flush and verification, and
  downstream device removal.
