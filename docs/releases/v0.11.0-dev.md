# NexOS v0.11.0-dev — Milestone 11 hardware installer

This prerelease moves the guided installer into NexOS itself. The release ISO
can install and verify a bootable NexOS system on a supported AHCI or legacy
IDE disk, then boot that disk directly through x86-64 UEFI firmware.

## Highlights

- Adds in-kernel `diskutil inspect`, `diskutil plan`, and `diskutil verify`
  commands.
- Adds `nex-install diskN ERASE-diskN` with an exact target-bound destructive
  confirmation.
- Creates and checks a protective MBR, redundant GPT headers and entry arrays,
  a BIOS-reserved partition, a 64 MiB FAT32 EFI System Partition, and a NexFS
  root partition.
- Adds native `no_std` FAT32 formatting and the long-file-name entry required
  for `limine.conf`.
- Embeds the running kernel and Limine `BOOTX64.EFI` in the release ISO as
  installer payloads.
- Copies the UEFI fallback loader, kernel, and boot configuration, formats the
  NexFS root, flushes storage, and reads the result back before reporting
  success.
- Detects the Limine boot source and refuses to erase a matching live disk.
  Installed systems intentionally omit the installer loader payload.
- Promotes the coalescing kernel heap to a 16 MiB global allocator so FAT32,
  GPT, and verification code can run in the freestanding kernel.
- Makes COM1 bidirectional, allowing the kernel monitor and installer to be
  operated from a serial console when PS/2 input is unavailable.

## Verification

- All 22 focused `nexfs` and `nexos-storage` tests pass.
- Strict Clippy checks pass for the host workspace, and the custom-target
  x86-64 kernel links with `core`, `alloc`, and `compiler_builtins`.
- The hybrid release ISO boots under QEMU Q35 UEFI, loads both installer
  payloads, detects a blank 256 MiB AHCI disk, previews its exact layout, and
  completes `nex-install disk0 ERASE-disk0`.
- `diskutil verify disk0` independently verifies the GPT structures, UEFI
  loader bytes, kernel size and CRC32, Limine configuration, and NexFS UUID.
- With the ISO removed, QEMU UEFI loads the installed
  `EFI/BOOT/BOOTX64.EFI`, starts NexOS 0.11.0-dev, rediscovers the installed
  disk, and reaches the interactive monitor.

## Hardware requirements and limitations

This is a real-hardware installer preview, not a universal hardware release.
The install path requires x86-64 UEFI, Secure Boot disabled, 512-byte logical
sectors, an AHCI or legacy IDE target, framebuffer firmware support, and
PS/2/i8042 or COM1 input. It performs a guided whole-disk erase.

Legacy-BIOS stage installation from inside NexOS, partition-preserving manual
mode, NVMe, 4Kn disks, USB mass-storage transfers, live USB HID endpoint input,
SMP, networking, and filesystem-backed ring-3 commands remain future work.
The release ISO still boots through either BIOS or UEFI, while the newly
installed physical disk is UEFI-only.
