# NexOS v0.8.0-dev — Milestone 8 userspace shell core

This development release adds the freestanding userspace ABI library and the
bounded Unix-inspired shell frontend that future ring-3 commands will share.

## Highlights

- New `nexos-userspace` `no_std` workspace crate.
- Native x86-64 NexOS syscall wrapper and shared negative-error decoding.
- Safe host stub for userspace unit testing.
- Shell parsing for quotes, escapes, `$NAME` expansion, pipelines, `<`, `>`,
  and `>>`.
- Fixed-capacity environment and 16-entry adjacent-deduplicating history.
- Explicit errors for malformed pipelines, missing or duplicate redirections,
  unterminated quotes, trailing escapes, and capacity overflow.
- Registry of 45 planned built-in, file, system, storage, and utility commands.
- Kernel diagnostics `commands`, `shellparse`, and `shelltest`.

## Verification

- All 43 host unit tests and documentation tests pass.
- Strict Clippy checks pass with warnings denied.
- `nexos-userspace` passes a custom-target `no_std` build.
- The freestanding x86-64 kernel links with the userspace frontend.
- QEMU BIOS and UEFI boots run `shelltest` and report two parsed pipeline
  stages with expanded `/home/root` and output redirection to `/tmp/count`.
- Raw disk and hybrid ISO media reach the v0.8 monitor in BIOS and UEFI modes.

## Current limits

This release completes the syscall-facing userspace library, shell language,
state containers, and command namespace. The boot prompt is still the kernel
diagnostic monitor: NexFS-backed executable packaging, process-connected pipe
handles, command implementations that mutate mounted filesystems, and the
final interactive ring-3 shell remain integration work.

## Release images

The prerelease provides a hybrid BIOS/UEFI ISO, a zipped 128 MiB raw disk
image, and a SHA-256 checksum file. Secure Boot must be disabled.
