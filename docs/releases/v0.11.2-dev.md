# NexOS v0.11.2-dev — installer regression polish

This polish prerelease makes the no-ISO boot guarantee an automated release
requirement and records the next implementation milestones.

## Highlights

- Adds `scripts/qemu-installer-smoke.py`, a cross-platform serial-console QEMU
  harness.
- Creates a disposable 256 MiB AHCI disk and drives the exact in-OS command
  `nex-install disk0 ERASE-disk0`.
- Waits for the ninth progress step and the installer's post-write
  verification result.
- Removes the ISO and boots the installed disk in a fresh SeaBIOS VM.
- Boots the same disk again in a fresh UEFI VM.
- Requires both firmware paths to reach the interactive `nexos>` prompt.
- Runs this regression in GitHub Actions before checksums and release assets
  are published.
- Corrects the final disk-utility help text to describe its combined BIOS/UEFI
  layout.

## Verification

- The new harness passed locally with QEMU 11.0.0 and the exact
  v0.11.2-dev release ISO.
- The full guided installation completed and verified.
- The installed disk reached the NexOS prompt with no ISO attached under both
  SeaBIOS and UEFI.
- Host tests, strict Clippy, and the freestanding kernel build remain required
  before the new QEMU publication gate.

## Next milestones

Milestone 12 will complete live xHCI class I/O for USB keyboards, mice, hubs,
and mass-storage block devices. Milestone 13 will mount NexFS as the live root
and make the ring-3 shell execute filesystem-backed programs. SMP/platform
completion and NVMe/hardware expansion follow in Milestones 14 and 15.
