# NexOS v0.14.0-dev - SMP and platform services

Milestone 14 activates multi-processor startup and the ACPI platform services
that previous releases only discovered.

## Highlights

- Starts up to 64 x86-64 CPUs through Limine and records processor/LAPIC IDs,
  online state, BSP scheduler ticks, and application-processor idle activity.
- Loads the shared NexOS GDT and IDT on APs and enables each local APIC before
  entering an interruptible idle loop.
- Maps and enables HPET as the monotonic millisecond clock while retaining PIT
  scheduler ticks and automatic fallback.
- Enumerates PCI segment zero through page-scoped ACPI MCFG ECAM mappings,
  with configuration mechanism 1 fallback.
- Parses FADT reset and PM1 control registers plus DSDT `_S5_` sleep types.
- Adds working `smpinfo`, `uptime`, `shutdown`, and `reboot` commands to
  installed ring-3 `nexsh`; power commands are also available in recovery.
- Adds `smpinfo` and expands ACPI, PCI, and uptime diagnostics with the active
  backend and per-CPU state.

## Release gates

- 77 host unit tests, strict Clippy, optimized freestanding userspace, and a
  warning-free kernel build.
- Four-CPU SeaBIOS and UEFI boots requiring every AP online, HPET active, PCI
  ECAM active, ACPI S5 shutdown, and ACPI reset to terminate the VM.
- Guided installation followed by four-CPU no-ISO SeaBIOS/UEFI boots,
  ring-3 filesystem commands, and ring-3 ACPI shutdown.
- Existing xHCI hub, USB-only HID, USB-disk installation, cache flush,
  readback, and disconnect coverage with four CPUs present.

## Current boundary

Application processors are online and ready for interrupt/IPI work, but user
tasks stay on the bootstrap processor. Cross-CPU task migration requires
per-CPU TSS and syscall stacks and remains future work.

## Next milestone

Milestone 15 focuses on storage and hardware expansion: NVMe, 4Kn media,
broader recovery/hotplug behavior, a physical-machine compatibility matrix,
and longer stress testing.
