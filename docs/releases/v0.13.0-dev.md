# NexOS v0.13.0-dev - filesystem-backed userspace

Milestone 13 turns the existing ELF, syscall, VFS, and NexFS foundations into
the first default ring-3 environment on installed systems.

## Highlights

- Builds an optimized freestanding x86-64 `/bin/nexsh` ELF separately from the
  kernel and installs it into NexFS and the boot filesystem.
- Discovers the NexFS GPT root partition during boot and falls back safely to
  the kernel recovery monitor when no root is available.
- Reads `/bin/nexsh` from NexFS, validates ELF64 bounds and permissions, maps
  load segments, zeroes BSS, and creates a correctly aligned 64 KiB user stack.
- Validates complete user pointer ranges before console and filesystem
  syscalls access memory.
- Implements stdin/stdout, Open, Close, Read, Stat, and ReadDir kernel services
  for the foreground userspace process.
- Adds working `help`, `uname`, `pwd`, `echo`, `ls`, `cat`, `stat`, `clear`, and
  `exit` commands at the default `nexsh>` prompt.
- Keeps `nexos>` as a recovery and installer monitor when booting the ISO or a
  disk without a valid NexFS root.
- Fixes blocking syscall input so IRQs can wake the CPU without violating the
  masked syscall-dispatch invariant.

## Release gates

- 74 host unit tests and strict Clippy checks.
- Freestanding optimized userspace ELF, kernel, and hybrid BIOS/UEFI ISO
  builds.
- Guided installation followed by no-ISO SeaBIOS and UEFI boots.
- Both installed boots must launch `/bin/nexsh`, run ring-3 `uname`, read
  `/etc/nexos-release`, and enumerate `/` from NexFS.
- Existing xHCI hub, USB-only HID, USB-disk installation, cache flush,
  readback, and disconnect coverage.

## Current boundary

The first shell is one synchronous foreground process using the boot page
table. Standalone process spawning, separate address spaces, pipelines,
redirection execution, background jobs, and broader POSIX behavior remain
future milestones.

## Next milestone

Milestone 14 will focus on SMP and platform completion: application-processor
startup, per-CPU state, HPET timekeeping, PCI ECAM, and ACPI power control.
