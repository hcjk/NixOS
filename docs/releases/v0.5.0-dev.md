# NexOS v0.5.0-dev — Milestone 5 storage

This development release adds the first complete storage path from PCI
discovery to validated sectors and filesystems.

## Highlights

- SATA AHCI polling DMA with BIOS handoff, ATA IDENTIFY, LBA28/LBA48
  read/write, flush, timeouts, and error reporting.
- Legacy PCI IDE polling PIO with primary/secondary and master/slave
  discovery, IDENTIFY, LBA28/LBA48 read/write, flush, and timeouts.
- Shared bounded block-device and partition-device interfaces.
- Write-back LRU sector cache.
- Primary MBR and GPT header/entry-array validation, including CRC, bounds,
  and overlap checks.
- Native `no_std` FAT32 read/write support for nested 8.3 files and
  directories.
- New `lsblk` and read-only `disktest <N>` kernel-monitor commands.
- BIOS/UEFI bootable raw image tooling for QEMU, VMware, and compatible
  x86-64 hardware with Secure Boot disabled.

## Verification

- All 17 host unit tests and all documentation tests pass.
- Strict Clippy checks pass with warnings denied.
- The freestanding x86-64 kernel builds successfully.
- QEMU 11.0.0 Q35 BIOS and UEFI boots discover and read a 128 MiB AHCI disk.
- QEMU legacy `pc` boots discover and read the same image through IDE PIO.
- AHCI and IDE both pass the read-only LBA 0 CRC32 monitor test.

## Current limits

This remains an early kernel-monitor release. It has no userspace, VFS mount,
Unix shell, USB, NVMe, networking, or physical-disk installer. FAT32 creation
currently uses 8.3 names; long-file-name creation is deferred. Storage I/O is
synchronous and polling. Raw physical disk operations remain intentionally
disabled.
