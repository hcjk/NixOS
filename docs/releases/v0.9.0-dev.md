# NexOS v0.9.0-dev — Milestone 9 USB foundation

This prerelease brings up real xHCI hardware paths and introduces the reusable
USB protocol core.

## Highlights

- Discovers PCI xHCI controllers and performs bounded firmware ownership
  handoff, halt, reset, capability validation, and controller startup.
- Programs DCBAA, command ring, event ring, ERST, interrupter-zero state, and
  controller scratchpads using physical DMA memory.
- Powers root ports, resets USB 2 devices, and reports USB 2/3 connection,
  enable, link, power, and speed state.
- Executes No-Op, Enable Slot, and Address Device commands through xHCI command
  and event rings.
- Performs endpoint-zero `GET_DESCRIPTOR` and `SET_CONFIGURATION` transfers,
  assigning addresses and classifying complete configuration trees.
- Adds `lsusb`, `usbinfo`, and `usbtest` monitor commands.
- Adds an allocation-free `nexos-usb` crate for descriptors, enumeration, xHCI
  TRBs, boot HID reports, one-level hub state, and USB mass-storage BOT/SCSI
  packets.

## Verification

- 61 host tests pass, including 18 new USB-specific tests.
- Strict host Clippy checks pass with warnings denied.
- The freestanding x86-64 kernel links successfully.
- QEMU 11 xHCI testing addresses and configures an emulated USB keyboard and
  USB mass-storage device in the same boot.
- The mass-storage descriptor test reports VID/PID `46f4:0001`, USB 3.0, one
  mass-storage interface, and two bulk endpoints.
- The final raw disk image and hybrid ISO are boot-tested through both legacy
  BIOS and UEFI before publication.

## Known limitations

This is the USB foundation release. Devices are addressed, configured, and
classified, but live HID interrupt transfers, downstream hub enumeration,
USB mass-storage block I/O, hotplug recovery, and xHCI interrupt delivery are
not enabled yet. PS/2 remains the monitor input, and SATA AHCI/legacy IDE remain
the live storage transports.

Secure Boot is not supported. Use the hybrid ISO for VMware virtual CD/DVD
boot or the zipped raw image for direct disk-image testing.
